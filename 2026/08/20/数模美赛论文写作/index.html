🛠️ 工具与数据源速查

数据分析与可视化

  • Excel：数据分析与精美走势图。
  • SPSS：专业统计模型分析。
  • Origin：强大的科研数据可视化与拟合。
  • Echarts / Hiplot：强烈推荐的在线图表库。
  • Lingo：线性与通用优化求解器（规划模型）。
  • Matlab / Python：交互式编程平台，整合算法与工具库。

文献阅读与翻译

  • 知云文献阅读器：阅读与翻译一体化。
  • DeepL：高质量机器翻译，效果优于传统翻译器。

绘图与展示

  • VISIO / 亿图：流程图、结构图、系统图。
  • Axure / 小yph：专业矢量绘图，适合界面与结构示意。
  • Excel / PPT：也可绘制美观统计图。

📊 综合性数据平台

  • CNKI 知网：https://data.cnki.net/ - 提供经济、社会、金融等权威统计数据。
  • 199IT 大数据导航：http://hao.199it.com/ - 全球主要数据来源导航，汇聚各国统计局、世行等入口。
  • EPSDATA：https://www.epsnet.com.cn/ - 宏观经济、区域发展等多维度数据。
  • UNdata：https://data.un.org/ - 联合国官方统计数据库。

🌍 国际与开放数据源

  • Awesome Public Datasets：https://github.com/awesomedata/awesome-public-datasets - 社区维护优质公共数据集，覆盖多领域。
  • ICPSR：https://www.icpsr.umich.edu/ - 密歇根大学社会科学数据存档。
  • Our World in Data：https://ourworldindata.org/ - 牛津大学开放数据项目，支持在线可视化。

💡 机器学习与数据竞赛平台

  • Kaggle：https://www.kaggle.com/datasets - 全球知名数据科学社区，海量公开数据集。
  • 天池数据集：https://tianchi.aliyun.com/dataset/ - 阿里云行业实战数据集（金融、医疗等）。

🧩 缺失数据怎么补？（”编数据”技巧）

  1. 插值补全法：适用于缺失值少。常用线性插值、样条插值、多项式拟合、移动平均法。（💡 工具：Excel、Python pandas.interpolate()、R）
  2. 语义/逻辑建模法：根据逻辑推导合理趋势，确保符合客观规律。可用回归模型、系统动力学等构造虚拟数据。（📘 示例：若”GDP年增5%”，可用指数增长模型生成模拟数据）
  3. AI 工具生成：用 GPT 生成符合逻辑的数据表，生成后需人工核查合理性并注明来源为合成数据。

    🧠 Prompt 示例：帮我生成一组 2010–2024 年的中国 GDP、CPI、进出口数据，要求符合现实增长趋势，带上单位。

📝 论文写作框架与核心要点

Summary Sheet（摘要页）

写法同国赛。

标题与关键词

标题三种写法：

  1. 基于主要模型/方法：如 An Integrated Production–Waste–Harm Model Based on… （注意介词小写，如 of, on, at, in）
  2. 直接使用赛题题目/研究问题：如 Global Disposable Plastic Waste Crisis
  3. 简短创意型（偏社会/经济/文化）：如 The Wandering Homeland 或 NOT ME, US!

关键词（Keywords）：一般选 3-6 个，可放模型、方法名或论文核心内容词。部分论文不写，但建议加上。

Contents（目录）

Introduction（引言）

Background（背景）：总结题目背景及自查资料，切忌照搬原题。小技巧：美赛问题较开放，背景介绍可侧重往自己的研究方向靠拢。

Restatement of the Problem（问题重述）：用简明扼要的语言重述问题，绝不可照抄原题！

通用模板：
Considering the background information and restricted conditions identified in the problem statement, we need to solve the following problems:

  • Problem 1
  • Problem 2
  • Problem 3

AI 辅助 Prompt：

你是一位数学建模高手，这是数学建模美赛，请根据问题原背景和问题要求以及格式c和要求b，用英文写Introduction的Background和Restatement of the Problem部分。

文献综述 Literature Review

核心内容三方面：

  1. 前人研究方向：有哪些学者研究过。（💡 Many researchers have focused on modeling…）
  2. 前人方法与结论：用了什么方法，得出什么结果。（💡 Duch et al. used the method of…）
  3. 与本文关联：前人研究提供的启发。（💡 Their findings provided a foundation for…）

写作注意：

  • 规范引用标注：上标 [1], [2]。
  • 语气客观中立，避免评价性词汇（如”很好”、”错误”）。
  • 逻辑衔接自然，与自身研究呼应，不可”断层”。

AI 辅助 Prompt：

请帮我撰写一段英文的Literature Review，用于数学建模论文，要求：主题：[填写具体题目]；内容包括：前人主要研究方向、使用方法、取得结论；最后指出这些研究为本文提供的启发；保持正式学术语气，长度约200字。










Assumptions and Justifications（模型假设与合理性验证）

美赛对此部分评分极严，所有用到的条件、前提、数据简化均需清晰列出并论证合理性。若不合理或解释不充分，评委会要求重新思考。

假设常见类型：点击图片可查看完整电子表格。

合理性论证角度：

  • 现实依据（如”根据统计规律…”、”根据经验观察…”等）### 模型假设与合理性论证

在数学建模中，提出假设需包含三大要素：理论支持（如基于牛顿第二定律）、可行性解释（如受数据限制所作的近似）以及对模型影响的说明（如该简化不影响主要结论）。

✅ 示例解析

示例 1：假设的提出与论证

Assumption: The criminal’s movement is not constrained.
Justification: Although in reality criminals move within a city grid limited by streets and buildings, we approximate this by a “Manhattan Grid” layout. This simplification allows modeling the movement along grid edges, which corresponds closely to real-world paths.

解析：明确假设条件 → 说明实际与理想的差别 → 提出合理简化方法 → 强调假设与现实相符的逻辑。

示例 2：2020年美赛优秀论文节选

Assumption 1: Data involving only actions on the ball are sufficient to model football gameplay.
Justification: Though we do not know every player’s exact position, actions on the ball reveal enough about the team’s structure and performance. It is widely accepted that controlling the ball reflects effective play; thus, this assumption is reasonable.

解析：限定数据范围 → 说明限制仍具代表性 → 用领域知识支撑可行性 → 突出核心逻辑。

✍️ 写作技巧与 Prompt 模板

写作规范：

  1. 逐条编号列出假设（Assumption 1, 2, 3…）；
  2. 每条假设后紧跟合理性解释；
  3. 格式统一，逻辑连贯；
  4. 使用正式学术表达，如：
    • We assume that…
    • This assumption is reasonable because…
    • This simplification allows us to…
    • In practice, this assumption is widely accepted…

AI 辅助写作 Prompt 模板：

符号说明

符号说明部分应以表格形式呈现，包含符号、含义和单位三列。若无单位，用短横线“–”代替。表格上方需添加说明语：“Important notations used in this paper are listed in Table 1”。

AI 辅助写作 Prompt 模板：

论文主体结构

标准的数学建模论文主体通常按问题拆分，并辅以必要的分析与总结：

  1. The name of model 1（模型1的建立和求解）：用于解决题目中的第一个问题。

  1. The name of model 2（模型2的建立和求解）：用于解决题目中的第二个问题。
  2. The name of model 3（模型3的建立和求解）：用于解决题目中的第三个问题。
  3. Sensitivity Analysis（灵敏度分析）
  4. Model Evaluation and Further Discussion（模型的评价和进一步的讨论）
  5. Conclusion（结论）
  6. References（参考文献）
  7. Appendices（附录）

🧩 美赛论文写作与建模八步法

1. 学会模仿：模仿 O 奖论文

学习优秀论文的结构、逻辑和表达方式，从高质量作品中提炼思路。

2. 选好题目：选择最适合你们的题目

根据团队能力、数据可得性、兴趣和创新点挑选题目。

3. 写好标题：适当地生动一些

标题需简洁明了、吸引人，且准确反映研究主题。美赛 O 奖论文中常规标题较少，多采用以下更有吸引力的形式：

  • 两段式：Crack the Wordle Puzzle: Word Attribute Analysis Approaches（破解 Wordle 之谜：词语属性分析方法）
  • 有吸引力的：Uncover the Hidden Secrets in Wordle Results（揭开 Wordle 结果中隐藏的秘密）
  • 简约的：Winners in Wordle（Wordle 中的获奖者）
  • 常规的：Viral Spread Characteristics and Difficulty Determinants of Wordle Modeling Based on Differential Equations and K-nearest Neighbors

4. 着重摘要：美赛初评主要看摘要质量

常用模板：

  • 开头段：针对什么问题，建立了什么模型。
  • 针对问题一：建立的模型 + 求解的过程 + 得到的数值 + 意义。
  • 针对问题二：同上。
  • 针对问题三：同上。
  • 结尾总结段：模型的优缺点、灵敏度分析等，以及可以改进的方面（非必要）。

要点提示：

  • 模型名称、算法名称、关键变量、模型结果常常要加粗；
  • 摘要页应控制在一页内。

注意事项：

  • 模型算法的专有名词不能错；
  • 每一个小问都要给出明确的结果（包括数值或文字描述）；
  • 每一个关键模型都要结合题目描述如何设置参数和求解；
  • 语言简洁精炼，逻辑必须清晰，方便评委快速定位模型与结果。

5. 模型建立与求解：模型要结合问题，算法要有优越性

模型需贴合实际问题，并选择恰当或改进的算法进行求解。

6. 结果分析：分析到位，表格要引用

得到结果后必须对结果进行详细分析，不仅要给出结果，还要解释原因、验证可靠性。

7. 灵敏度分析：结合图表，有图有分析

利用图表展示结果变化和趋势，增强说服力，美赛对此较为注重。

8. 学会包装：美化绘图，做好排版

图文并茂、排版整洁，整体视觉效果专业美观。
